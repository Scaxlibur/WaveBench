# 会话与恢复

一次仪器连接对应一个会话 epoch。WaveBench 用资源租约和事务锁避免同一资源被并发操作，并把会话状态与已确认字段绑定到该连接，而不是跨连接复用旧判断。

## 健康状态

会话状态从 `healthy` 开始；发生不确定 I/O 或无法确认的写入后会降级为 `uncertain` 或 `poisoned`，关闭后为 `closed`。降级是单向的：只有操作合同定义的独立验证才能恢复可用状态，普通调用不能自行把不确定状态改回健康。

## 恢复不是重试

恢复只处理明确、有限且可验证的安全动作。例如某些合同允许一次受 guard 的关闭操作，再独立读取状态。它不是 reset，也不会自动恢复所有配置、输出或设备私有状态。无法证明恢复结果时，保守状态仍然有效。

## 对 run 的意义

run 在打开服务前按确定顺序取得资源租约，并在结束时关闭会话和释放租约。artifact 可记录 operation 的结构化证据，但不能代替运行后再次读取真实仪器状态。
