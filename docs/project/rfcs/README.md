# RFC 索引

本目录保存尚在评审或已经形成决策的核心接口提案。RFC 记录问题、约束、兼容性和验收门槛，不替代已实现功能的参考文档。

RFC 使用以下状态：

- `Draft`：提案仍可修改，不得据此宣称接口已经提供；
- `Accepted`：关键合同已经冻结，可以按实施顺序修改代码；
- `Implemented`：合同已经进入正式版本，稳定用法已同步到 `reference/`；
- `Superseded`：由后续 RFC 取代，并保留替代关系。
